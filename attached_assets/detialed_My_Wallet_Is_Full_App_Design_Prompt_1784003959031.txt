# User-Controlled Data Only

Every chart, card, statistic, recommendation, budget, and AI insight must be generated **only** from user-entered data.

The application must never invent:

* Salary
* Expenses
* Investments
* Savings
* Goals
* Transactions
* Reports
* Analytics
* Predictions

No financial information should appear until the user has entered it.

---

# Overall Experience

The application should feel calm, uncluttered, and trustworthy. It should prioritize fast expense entry, clear financial visibility, and long-term savings management. Every screen should emphasize simplicity, with plenty of whitespace, subtle animations, and intuitive navigation. The design should remain data-driven, showing only information the user has explicitly entered rather than relying on mock or demo content. This ensures a clean first-run experience and builds user trust from the start.
